Check this mint

Paste a bMintX link or transaction id. Your browser checks the signature, the merkle proof and the block’s proof of work itself, so you don’t have to trust us or anyone else.

Optional: drop the original file to check it is the one minted. It is hashed in your browser and never uploaded.

What gets checked

  1. The transaction’s bytes hash to the id you gave.
  2. The mint’s signature verifies for that exact output and names the signing key.
  3. Your file, if you gave one, has the same SHA-256 as the minted bytes.
  4. The merkle proof leads to the block header’s merkle root.
  5. The header’s proof of work checks out here, and two independent sources (WhatsOnChain, Bitails) give the same header.

If a source can’t be reached the answer is “Couldn’t check”, never “Verified”. Verify contract inspired by Lightweb bfinger (Apache-2.0).
